# runtime

## Назначение

Нейтральный каталог runtime для backend, архитектурных проверок и административного интерфейса.

## Что здесь является источником истины

`service-catalog.json` содержит ownership, зависимости, readiness, события и публичные маршруты.

## Что агент должен знать перед изменениями

Поле `composeService` сохранено как совместимое имя сериализованного контракта; значение теперь является именем Kubernetes workload. `kubernetesNamespace` указывает namespace. Запуск не использует Compose. Каталог не содержит секретов. Только `kind=application` разрешает административный restart; базы, frontend и панели не входят в этот список.
